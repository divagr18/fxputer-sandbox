# fxputer-sandbox

A tiny inventory library, used as a target repository for an experiment: pull requests here are opened by [fx](https://github.com/vercel-labs/fx), a coding agent, running on the RISC-V CPU compiled into the weights of [Qwenputer](https://github.com/divagr18/qwenputer), with Qwen3.5-4B as its model.

Run the tests with `python -m unittest`.
